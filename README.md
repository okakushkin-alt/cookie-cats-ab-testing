# Cookie Cats — A/B-тест удержания игроков

Небольшой проект по анализу A/B-теста мобильной игры Cookie Cats с использованием Python.

## Цель проекта

Проверить, влияет ли перенос игрового ограничения с 30-го на 40-й уровень на удержание игроков.

## Инструменты

- Python
- Pandas — обработка и анализ данных
- SciPy — статистические тесты
- Matplotlib — визуализация результатов
- Google Colab — среда выполнения анализа

## Данные

Использован открытый датасет [Mobile Games A/B Testing — Cookie Cats](https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats).

Датасет содержит 90 189 игроков и пять столбцов: идентификатор игрока, экспериментальная группа, число игровых раундов и признаки возвращения на следующий день и через 7 дней.

## Методы анализа

- Проверка пропусков и дубликатов.
- Сравнение размеров экспериментальных групп.
- Расчёт удержания игроков на следующий день (D1) и через 7 дней (D7).
- Проверка различий с помощью критерия хи-квадрат.
- Расчёт 95%-х доверительных интервалов разницы долей.
- Визуализация результатов A/B-теста.

## Результаты

| Показатель | gate_30 | gate_40 |
|---|---:|---:|
| Количество игроков | 44 700 | 45 489 |
| Среднее количество раундов | 52,46 | 51,30 |
| Медиана раундов | 17 | 16 |
| Удержание D1 | 44,82% | 44,23% |
| Удержание D7 | 19,02% | 18,20% |

### Статистические результаты

- **D1:** разница +0,59 процентного пункта; p-value = 0,07441. Статистически значимое различие не обнаружено на уровне 5%.
- **D7:** разница +0,82 процентного пункта; p-value = 0,00155. Удержание в группе `gate_30` статистически значимо выше.
- После поправки Бонферрони на две проверенные метрики результат D7 остаётся статистически значимым.

## Бизнес-вывод

В рамках эксперимента группа `gate_30` продемонстрировала более высокое недельное удержание игроков. Перенос ограничения на 40-й уровень не показал преимущества по изученным метрикам.

Для окончательного продуктового решения следует дополнительно исследовать монетизацию и другие показатели поведения игроков.

## Как запустить

1. Откройте `cookie_cats_analysis.ipynb` в Google Colab.
2. Скачайте исходный CSV из указанного источника Kaggle.
3. Загрузите CSV через ячейку импорта файла.
4. Выполните ячейки ноутбука последовательно.
